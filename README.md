
# 🎨 Color Palette Generator

A sleek and interactive color palette generator built with **Next.js**, **TypeScript**, and **Tailwind CSS**. This tool helps designers, developers, and creatives generate harmonious color palettes for their projects.

---

## 🌐 Live Demo

👉 [View Live on Vercel](https://color-palette-generator-28jf11x9e-chelse-s-projects.vercel.app/)

---

## ✨ Features

- 🎲 Generate random color palettes
- 📋 Copy HEX codes with one click
- 💾 Save your favorite palettes
- 🔄 Regenerate colors
- Responsive design using Tailwind CSS

---

## 🚀 Getting Started

### 1. Clone the Repository

git clone https://github.com/chinu21123/color-palette-generator.git
cd color-palette-generator


### 2. Install Dependencies

Using **pnpm** (preferred):
`bash
pnpm install


Or using **npm**:


npm install


### 3. Run Locally


pnpm dev
# or
npm run dev


Then open [http://localhost:3000](http://localhost:3000) in your browser.
